# Imagens do "Comece aqui" (prompts para o ChatGPT)

O "Comece aqui" já funciona sem imagens: os esquemas (trem do verbo, casinhas dos gêneros, fluxo do dia), os desafios e o jogo de ligar pares são desenhados pelo próprio app. As imagens abaixo são a ilustração de abertura de cada aula, para deixar o começo mais leve e convidativo.

## Como gerar e salvar

1. Abra o ChatGPT e cole **primeiro o bloco de estilo** (abaixo), sozinho, numa conversa nova. Assim todas as imagens saem com a mesma cara. Ele é o mesmo das imagens Pocket, com um toque mais lúdico para quem está começando.
2. Depois cole um prompt por vez. Gere em **formato paisagem (3:2, 1536 × 1024)**.
3. **Confira o texto escrito na imagem.** Geradores às vezes erram letras em alemão (ä, ö, ü, ß). Se sair errado, peça: *"Regenerate, the label must read exactly: …"*. Se continuar errado, peça a versão sem texto: o app já mostra todas as palavras certas logo abaixo.
4. Salve como **PNG** com o nome indicado (por exemplo `guia-mapa.png`) na pasta `images/guia/` do projeto.
5. Me avise quando tiver as imagens: eu comprimo para WebP, coloco os nomes em `images/guia/index.json` e publico. O app só mostra as imagens listadas; as que ainda não existirem simplesmente não aparecem.

## Bloco de estilo (cole primeiro, uma vez)

```
You will create a series of illustrations for the beginner module of a German-learning app called "Deutsch-Trilha".
Use this exact style for every image in this conversation:
- Flat, modern editorial illustration with a gentle isometric feel, clean vector shapes, soft gradients and a subtle paper grain.
- Playful, warm and encouraging mood, like a friendly picture book for adults; expressive but simple characters, no caricature.
- Palette: deep navy (#0e1525) and slate blue for shadows and backgrounds, warm orange (#ff8a3d) and golden yellow (#ffcf4a) as accents, off-white (#f5f9fc) highlights, a touch of teal. Grammar colors when asked: blue (#1f6fcf) for "der", red (#d23a5c) for "die", green (#16894b) for "das".
- People: diverse adults, natural proportions, simple faces, no celebrities, no brand logos, no real company names.
- Composition: landscape 3:2 (1536x1024), one clear focal point, generous empty space, good contrast so it reads well on a dark app screen.
- Text inside the image: only the words or letters I explicitly list, spelled exactly as written, in a clean bold sans-serif. Never invent other words, never add English or Portuguese text, no watermarks.
Reply "ok" and wait for my first prompt.
```

## Facilitações gráficas que o app já desenha

Estas não precisam de imagem: são feitas em código, com cor e áudio, e já estão nas aulas.

| Aula | Facilitação |
| --- | --- |
| Boas-vindas | Fluxo "uma semana na trilha" (6 lições → checkpoint → próximo degrau) |
| Seu dia de estudo | Fluxo das 4 etapas + jogo de ligar cada etapa ao que se faz nela |
| Truques da memória | Linha das revisões (hoje → 1 dia → 3 dias → 1 semana → 1 mês) |
| Sons (3 aulas) | Tabelas de sons com áudio + desafios "ouça e escolha" (schön/schon, Wien/Wein, nicht/Nacht) |
| Oi e tchau | Fluxo do dia (Guten Morgen → Guten Tag → Guten Abend → Gute Nacht) |
| Contar até 12 | Números com áudio + desafio de conta (drei + vier) |
| As peças da frase | Moldura colorida "Quem? / Faz o quê? / O quê?" |
| Pronomes | Fórmula radical + terminação |
| Três gêneros | Três colunas coloridas der/die/das com exemplos |
| Verbo no vagão 2 | Moldura do vagão 2 e moldura do verbo de duas partes |
| Casos sem medo | Tabela dos quatro "figurinos" do der |
| du ou Sie? | Comparação lado a lado de quando usar cada um |
